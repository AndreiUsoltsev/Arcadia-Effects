# AFX → Unity: модуль, экспорт, импорт

Эффекты редактора проигрываются в Unity без покадрового атласа модулем
**ArcadiaEffectsUnityModule** — https://github.com/AndreiUsoltsev/ArcadiaEffectsUnityModule.git
(UPM-пакет `com.interactivesoftware.arcadiaeffects`, Unity 2022.3+, проверен на 6000.0 и 6000.5).

Модуль — это ПОРТ движка редактора, а не отдельный рендер «по мотивам»:

- `Runtime/Core/*` — `js/core/utils.js, track.js, curve.js, path.js, model.js, sim.js` один в один
  (та же JS-арифметика: `|0`, `Math.imul`, mulberry32, целочисленный хэш шума);
- `Runtime/Rendering/*` — `js/core/engine.js` + `sprites.js` в RenderTexture через CommandBuffer
  (Canvas2D-наложение в премультиплицированной альфе, свечение, затухание, трейлы, postfx).

Отсюда главное правило этого скилла: **формат и движок редактора — контракт модуля.**

## Синхронизация движка (ЖЁСТКО)

Любая правка, меняющая результат симуляции или рендера, или формат файла, обязана
попасть и в модуль. Иначе эффекты в игре разъедутся с тем, что видно в редакторе.

| Правка в редакторе | Что сделать в модуле |
|---|---|
| Новое поле в документе / слое / `pt` / `em` / `fx` (+ дефолт в `Model.migrate`/фабрике) | То же поле с тем же дефолтом в `Runtime/Core/Model.cs` (`*.Read`) |
| Изменение `sim.js` (физика, эмиссия, rng-порядок) | Тот же код в `Runtime/Core/Simulation.cs`; порядок вызовов rng — побитово тот же |
| Изменение `utils.js` (шумы, хэши, изинг) | `Runtime/Core/Js.cs`; шум искажения ещё и в `ArcadiaPost.shader` (проход 5) |
| Изменение `engine.js` (рендер, наложение, postfx) | `Runtime/Rendering/ArcadiaEffectRenderer*.cs` + шейдеры `Runtime/Resources/ArcadiaEffects/*` |
| Новая процедурная фигура / параметр в `sprites.js` | `Runtime/Rendering/ShapeRasterizer.cs` (+ `ShapeLibraryInfo.VariantsOf` в `Model.cs`) |
| Новый тип слоя / эффект postfx | И модель, и рендер; без этого слой в Unity молча не рисуется |

Проверка паритета — инструменты в репозитории модуля (`Tools~/parity`, см. его `CLAUDE.md`):
дамп состояния симуляции из `js/core` (Node) против C#-порта по всем `library/*.json` —
число частиц совпадает во всех контрольных точках, расхождение координат ~1e-10
(последние биты `Math.sin/exp`). Картинка — регрессионный тест модуля против кадров редактора
(`Tests/Data/Golden`, кадры снимаются из этого редактора, порог mean < 1/255).

Если модуль недоступен в текущей сессии — НЕ делать вид, что синхронизация не нужна:
написать пользователю, какие файлы модуля надо поправить и почему.

## Экспорт эффекта из редактора

Файл эффекта — один JSON (`{app, v, doc, tex}`, текстуры внутри как data URL). Его и
читает Unity, ничего конвертировать не надо. Источники:

- `library/<Имя>.json` — сохранённый эффект (кнопка «Сохранить» / Ctrl+S при запущенном сервере);
- кнопка **Export** в панели каталога — скачать текущий эффект как `.json` с текстурами
  (работает и без сервера, когда каталог в localStorage).

Перед экспортом: сохранить эффект (несохранённые помечены точкой в каталоге — рабочая
сессия живёт в localStorage и в файл не попадает) и прогнать
`node tools/validate.mjs "library/<Имя>.json"` — без ошибок, у текстур есть пейлоад.

## Импорт эффекта в редактор

- кнопка **Import** в каталоге или перетащить `.json` в окно редактора;
- файл в `library/` + сервер — эффект в каталоге, открыть деп-линком
  `http://localhost:5179/?open=<Имя>.json&fresh=1`.

Старые файлы открываются всегда (`Model.migrate`); тот же `migrate`-путь повторяет модуль.

## Импорт в Unity

1. Пакет: Package Manager → Add package from git URL →
   `https://github.com/AndreiUsoltsev/ArcadiaEffectsUnityModule.git`
   (или папка пакета в `Assets/` проекта).
2. **Assets → Arcadia Effects → Import from Arcaidia library…** — выбрать `library/<Имя>.json`;
   он копируется в проект как `<Имя>.afx` и импортируется в `ArcadiaEffectAsset`:
   текстуры декодированы и премультиплицированы заранее (на мобильных и WebGL — со сжатием),
   атласы процедурных фигур запечены. Уже лежащие в проекте `.json` — меню
   **Convert JSON to .afx** (GUID сохраняется).
3. **GameObject → Effects → Arcadia Effect** (мир) или **GameObject → UI → Arcadia Effect (UI)**,
   назначить ассет. Центр композиции = позиция объекта, размер = px композиции / Pixels Per Unit.

Обновили эффект в редакторе — скопировать файл поверх `.afx` в Unity (или повторить
Import); ассет переимпортируется, сцены подхватят новую версию.

Запасной путь без импорта: `TextAsset` с JSON в поле **Effect** или `ArcadiaEffect.LoadJson(string)`
(тогда base64 и PNG декодируются при загрузке в игре).

## Эффект, который хорошо работает в Unity

Готовя эффект «для игры», помнить о цене механизмов — на ПК всё работает как в редакторе,
но веб и мобильные (уровни качества Medium/Low) режут дорогое:

- **Текстуры — только PNG/JPG.** WebP Unity не декодирует: импортёр пропустит текстуру с
  предупреждением (в библиотеке это Capacitor и Poison). Если исходник WebP — либо
  импортировать в редактор PNG, либо прогнать готовый JSON через
  `Tools~/ConvertWebpToPng.html` модуля.
- **Холст (RenderTexture) нужен слоям** со свечением слоя (`glowL`), затуханием (`fadeOn`),
  наложением screen/multiply, постэффектами и всему, что ПОД ними. Остальное на Medium/Low
  рисуется прямо в сцену. Эффект без этих механизмов (Sparks, Shockwave, Farm-*) в игре не
  держит ни одной RenderTexture — дешевле всего.
- **Трейлы** — MSAA и буфер глубины на холсте; длинная история (`hist` до 240 точек) ×
  тысячи частиц — самое дорогое (saber: 4300 частиц-трейлов). Для мобильных — меньше
  частиц-трейлов, короче жизнь.
- **Искажение (displace)** на Low выключается, смаз режется до 4–8 сэмплов, лимит частиц
  на эмиттер High/Medium/Low = 5000/2500/1200 (эмиттер с 4000 частиц на Low поредеет).
- Детерминизм, `pt.fps`, листы-футажи, `tintTex`, пути, суб-эмиттеры, силовые поля,
  пиксель-арт — поддержаны полностью.
